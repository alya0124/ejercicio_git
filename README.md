## 💡 El problema

Los equipos pierden tiempo y dinero cuando no saben **qué versión** está corriendo ni **si el servicio responde**.

## ✅ La solución

`obtener_status()` entrega el **estado y la versión** de tu aplicación al instante, lista para integrarse en cualquier panel, bot o pipeline.

```python
from status import obtener_status

print(obtener_status())
```
